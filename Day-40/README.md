# 🚀 Day 40 - Feature Selection

Welcome to **Day 40** of my **100 Days of AI/ML Engineering Journey**.

Today I learned about **Feature Selection**, an important part of the Machine Learning preprocessing pipeline.

Feature Selection helps us identify the most useful features from a dataset and remove irrelevant or redundant features.

---

## 🧠 What I Learned

### 1. What is Feature Selection?

Feature Selection is the process of selecting the most relevant features from a dataset while removing unnecessary features.

For example:

```text
Original Features:
Age
Salary
Experience
Student_ID
Random_Number

Selected Features:
Age
Salary
Experience
